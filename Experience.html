Now,In this page I am going to tell you my experince of learning HTML

My journey into web development began when I started learning HTML (HyperText Markup Language). HTML was one of the first programming-related technologies I explored, and it gave me an introduction to how websites are structured and built. At the beginning, I learned the basic structure of an HTML document, including elements such as `html`, `head`, `title`, and `body`. I gradually learned how to create headings, paragraphs, links, images, lists, and other elements to organize information on a webpage. Understanding how different HTML tags work together helped me see how the content and structure of a website are created. As I continued practicing, I started creating my own simple web pages using Sublime Text. Instead of only reading about HTML, I experimented by writing code, opening my pages in a browser, finding mistakes, and correcting them. Sometimes even a small mistake, such as placing a tag in the wrong position or forgetting to close a tag, would change how the entire page looked. Fixing these mistakes helped me become more careful and improved my understanding of HTML. One of my first projects was creating a personal portfolio webpage. Working on my portfolio gave me an opportunity to apply what I had learned and create something of my own. I also learned how to create and manage multiple HTML files so that I can build different pages for my portfolio. Learning HTML has made me more interested in web development and software engineering. Although I am still at the beginning of my journey, I have learned that building websites requires patience, practice, and problem-solving. I plan to continue learning CSS, JavaScript, and other programming technologies. So, I can create more advanced, interactive, and useful websites in the future. My experience with HTML is an important first step toward my long-term goal of becoming a Software Engineer. I look forward to improving my skills, working on more projects, and turning my ideas into real digital experiences.
